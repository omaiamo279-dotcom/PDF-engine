Enterprise PDF Workflow & Text-Replacement Engine

1. Select the document

2. Review the matches

Line numbers count the text lines on each page, from the top. Tick the matches you want to change.

No.PageLineContext

Privacy: your file is processed in memory and is not saved on the server. This is a public demo, so do not upload confidential documents.

Good to know: text is matched exactly as typed, including spaces. Scanned or image-only PDFs have no text to match. The new text is drawn in a plain font, and the old text is covered, not deleted.

Built with Java, Spring Boot and Apache PDFBox
